# Issue Tracker

- **Sistema**: GitHub Issues do repositório [alltomatos/mcpmail](https://github.com/alltomatos/mcpmail)
- **Fonte de verdade**: escopo, critérios de aceite, dependências (`Blocked by`)
  e status vivem nas Issues do GitHub — não em arquivos locais.
- **Branch de integração**: `develop` (features do PRD atual são mergeadas
  aqui antes do merge final para `main`).
- **Convenção de branch por Issue**: `issue-<numero>-<slug>`.
- **PRs**: uma PR por Epic concluído (todas as Issues fatiadas daquele Epic),
  aberta de `issue-<n>-...`/branch de trabalho para `develop`.
