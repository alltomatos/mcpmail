# Labels de Triage

Vocabulário padrão do framework `alltomatos/skills`:

| Label | Uso |
|---|---|
| `needs-triage` | Issue recém-criada, ainda não avaliada |
| `needs-info` | Falta informação do usuário/stakeholder para prosseguir |
| `ready-for-agent` | Escopo claro, critérios de aceite definidos, pronta para execução por agente |
| `ready-for-human` | Requer decisão ou ação humana (ex: mudança de schema, auth, API pública) |
| `wontfix` | Não será implementada |

## Labels adicionais de tipo/prioridade

| Label | Uso |
|---|---|
| `epic` | Issue mestre que agrupa Issues atômicas fatiadas |
| `P1` | Segurança / tipos |
| `P2` | Arquitetura |
| `P3` | Performance |
| `P4` | Higiene / documentação |
